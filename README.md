# Codex Echo Systems LLC website

Minimal static website for Codex Echo Systems LLC (CES), prepared for Apple Developer organization enrollment readiness.

## Pages

- `index.html` — CES identity and concise company statement.
- `about.html` — factual company purpose.
- `contact.html` — business email placeholders and mailto links.
- `privacy.html` — lightweight privacy information.
- `css/styles.css` — shared responsive styling.
- `assets/README.md` — logo asset note.

## Local preview

From `/workspace/ces-website`, run:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

This is staging material pending Founder approval of the domain and hosting. It is not deployed and does not include paid services, tracking, advertising, or product sales.
